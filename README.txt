HOMESTEAD
==========

Homestead는 작은 농장을 가꾸는 2D 픽셀 아트 농장 게임입니다.
땅을 갈고, 씨앗을 심고, 물을 준 뒤 작물을 수확해 판매하세요.
상점에서 새로운 씨앗을 사고, 일일 요청과 작물 도감을 완성할 수 있습니다.


실행 방법
---------

1. Homestead.exe와 data.pak를 반드시 같은 폴더에 둡니다.
2. Homestead.exe를 실행합니다.

필요 환경: Windows 10 이상, DirectX 11 지원 그래픽 환경


제출 파일
---------

Homestead.exe       게임 실행 파일
data.pak            게임 그래픽, 맵, 사운드 데이터
representative.sav  제출 검수용 대표 세이브 파일
README.txt          이 안내 문서

대표 세이브 파일은 제출 검수용입니다. 일반 플레이의 저장 파일은
Windows의 %LOCALAPPDATA%\Homestead 폴더에 만들어집니다.


조작법
------

WASD 또는 방향 키             이동
E, Space, 마우스 오른쪽 버튼  상호작용 및 수확
F, 마우스 왼쪽 버튼           선택한 도구 또는 씨앗 사용
1~8                            퀵슬롯 선택
I                              인벤토리 열기/닫기
ESC                            메뉴 열기/닫기
P                              충돌 영역 표시(확인용)


기본 플레이 방법
---------------

1. 농장의 경작 가능한 땅에서 괭이를 사용해 땅을 갑니다.
2. 씨앗을 선택해 경작지에 심습니다.
3. 물뿌리개로 작물에 물을 줍니다.
4. 집 안 침대 앞에서 E를 눌러 하루를 넘깁니다. 이때 저장됩니다.
5. 다 자란 작물에 E 또는 마우스 오른쪽 버튼을 사용해 수확합니다.
6. 농장 상점 표지판 앞에서 E를 눌러 씨앗을 구매하거나 작물을 판매합니다.
7. 집의 책장 앞에서 E를 눌러 작물 도감을 확인합니다.


저장과 초기화
-------------

저장은 침대에서 하루를 넘길 때만 실행됩니다.
게임 메뉴의 RESET SAVE를 두 번 선택하면 현재 플레이 세이브를 초기화할 수 있습니다.


라이선스 및 출처
----------------

이 프로젝트의 소스 코드는 MIT 라이선스입니다. 소스 코드는 상업적 또는
비상업적 용도로 사용할 수 있으며, 수정과 재배포가 가능합니다. 저작권 및
라이선스 고지는 유지해야 합니다.

중요: 이 MIT 라이선스는 게임 코드와 문서에만 적용됩니다. 게임에 사용된
그래픽, 배경음악, 효과음 및 기타 에셋에는 적용되지 않습니다.

그래픽 에셋: Kenmi Art의 구매 픽셀 아트 에셋을 사용했습니다.
배경음악: WhiteFoxGaming의 "FunCrafting"을 사용했습니다. 프로젝트 소유자가
확인한 조건은 로열티 프리, 상업적 이용 가능, 출처 표기 불필요, 수정 허용입니다.
효과음: Homestead를 위해 생성했으며 제3자 녹음물을 포함하지 않습니다.

원본 그래픽 에셋과 원본 음원 파일은 이 제출물에 포함하지 않습니다.
그래픽과 음악을 별도로 사용하려면 각 원 제작자의 라이선스를 따라야 합니다.
