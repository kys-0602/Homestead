# Homestead

작은 농장을 가꾸며 작물을 키우고 판매하는 2D 픽셀 농장 게임입니다. 큰 규모의 농장 생활 게임에서 재미있는 부분만 골라, 짧고 가볍게 즐길 수 있도록 만들었습니다.

![Platform](https://img.shields.io/badge/platform-Windows%2010%2B-blue)
![Language](https://img.shields.io/badge/language-C%2B%2B17-blue)

## 게임에서 할 수 있는 일

- 지정된 농지에 땅을 갈고, 씨앗을 심고, 물을 줍니다.
- 시간이 지나 자란 작물을 수확해 인벤토리에 넣습니다.
- 농장 상점 표지판에서 씨앗을 사고, 수확물을 팔아 골드를 모읍니다.
- 일일 요청을 완료해 추가 골드를 받습니다.
- 집의 침대에서 하루를 넘기며 저장합니다.
- 집 책장에서 작물 도감을 열어 수확한 작물과 판매 정보를 확인합니다.
- 농장의 닭과 개구리는 주변을 돌아다니며 플레이어와 충돌합니다.

## 진행 전략

이 프로젝트는 처음부터 많은 콘텐츠를 넣기보다, **작지만 끝까지 플레이할 수 있는 농장 생활**을 만드는 방식으로 진행했습니다.

1. 먼저 창을 열고, 픽셀 아트가 선명하게 보이며, 키보드와 마우스가 안정적으로 동작하는 기반을 만들었습니다.
2. 그 위에 이동, 충돌, 괭이, 물뿌리개, 씨앗, 작물 성장처럼 농사의 기본 흐름을 순서대로 추가했습니다.
3. 작물을 판매하고 씨앗을 사는 상점, 일일 요청, 인벤토리, 저장과 불러오기를 더해 반복해서 플레이할 이유를 만들었습니다.
4. 작물 종류와 품질, 작물 도감, 집 내부, 농장 배경 동물을 추가해 농장이 조금 더 살아 있는 공간처럼 느껴지도록 다듬었습니다.
5. 기능을 하나 넣을 때마다 빌드와 자동 테스트를 실행하고, 실제 플레이에서 확인된 문제를 바로 고쳤습니다. 예를 들어 상점 조작, 저장 위치, 타일 충돌, 동물 방향과 충돌 범위를 반복해서 보완했습니다.

## 가볍게 만든 이유

이 프로젝트의 제출물은 플로피 디스크 한 장 크기인 **1,474,560바이트 이하**여야 합니다. 그래서 다음 원칙을 지켰습니다.

- 게임에서 실제로 쓰는 그림과 소리만 골라 담았습니다.
- 원본 PNG, WAV 같은 큰 작업 파일은 게임에 넣지 않고, 실행용 데이터 파일로 정리했습니다.
- 작물, 동물, UI는 필요한 만큼만 단순하게 만들었습니다.
- 저장 파일에는 플레이에 필요한 변화만 기록했습니다.

최종 제출물은 `Homestead.exe`, `data.pak`, `representative.sav` 세 파일이며, 현재 합계는 **471,267바이트**입니다.

파일 크기와 실행 속도를 관리한 방법은 [최적화 전략](OPTIMIZATION_STRATEGY.md)에서 자세히 볼 수 있습니다.

## 조작법

| 입력 | 기능 |
|---|---|
| `WASD` 또는 방향 키 | 이동 |
| `E`, `Space`, 마우스 오른쪽 버튼 | 상호작용 |
| `F`, 마우스 왼쪽 버튼 | 선택한 도구 또는 씨앗 사용 |
| `1`~`8` | 퀵슬롯 선택 |
| `I` | 인벤토리 열기/닫기 |
| `ESC` | 메뉴 열기/닫기 |
| `P` | 충돌 영역 표시 (확인용) |

상점은 농장의 상점 표지판 앞에서 `E`를 눌러 열 수 있습니다. 저장은 집 안 침대 앞에서 `E`를 누른 뒤 하루를 넘길 때만 수행됩니다.

## 실행 방법

Windows 10 이상과 DirectX 11 지원 환경이 필요합니다.

개발용 실행 파일은 다음 명령으로 만들 수 있습니다.

```powershell
cmake --preset debug
cmake --build --preset debug
.\build\debug\Debug\Homestead.exe
```

배포용 Release 빌드는 다음과 같습니다.

```powershell
cmake --preset release
cmake --build --preset release
.\build\release\Release\Homestead.exe
```

더 자세한 빌드 환경 안내는 [CMAKE_BUILD_GUIDE.md](CMAKE_BUILD_GUIDE.md)를 참고하세요.

## 최종 제출물 만들기

```powershell
cmake --build --preset release --target HomesteadSubmission
```

완성된 파일은 `build/release/submission`에 생성됩니다.

## 검증

게임 규칙, 저장 파일, 입력, 화면 배치, 자산 데이터 등을 확인하는 자동 테스트 29개를 유지하고 있습니다. 최종 Release 빌드와 제출물 크기도 함께 확인합니다.

그래픽과 조작감은 자동으로 완전히 판단할 수 없으므로, 최종 제출 전에는 농장 이동, 재배·수확·판매, 저장 후 재실행, 창 전환, 소리를 한 번씩 직접 확인하는 것을 권장합니다.
